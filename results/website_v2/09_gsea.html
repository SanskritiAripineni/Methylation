Gene-set signals after correcting for a known array design bias.

In plain terms

Here we redo the pathway test the right way, using methods built specifically for methylation arrays that correct for the bias flagged earlier (genes with more spots are more likely to be 'hit' just by chance). The slope chart shows each longevity pathway's significance before correction (grey) and after (blue), with the p = 0.05 line marking the cutoff for 'significant.'

The pathway signals from Analysis 07 were re-tested with methods built for array methylation (missMethyl and methylGSA), which correct for the number of probes per gene. After correction, the longevity gene sets the project set out to examine did not remain significant.
