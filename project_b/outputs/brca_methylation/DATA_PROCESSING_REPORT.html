★ At a glance

This project classifies breast tumour vs normal tissue from genome-wide CpG methylation and interprets the affected gene programs. The headline result — a near-perfect classifier — is real and leakage-controlled; the pathway layer is honest but the weakest part. The detail below is what matters if you are auditing the methods.

2 Quality control & probe filtering

QC is unsupervised (label-blind) — it never uses the tumour/normal label — and is applied once, uniformly. Parameters and outcomes (from qc_summary.json):

Strengths
  • Label-blind QC cannot leak class information into the tumour-vs-normal contrast.
  • Sex chromosomes dropped — removes a major sex-driven methylation confounder.
  • The retained set is reused consistently as the statistical universe (not silently swapped later).
Caveats
  • No explicit probe blacklist named. Cross-reactive / SNP-affected probes (e.g. Zhou/Chen masks) are not documented as removed. Some retained probes may be technically unreliable.
  • No batch/array-position correction (e.g. ComBat) is described. For a tumour-vs-normal contrast this is low-risk given effect sizes, but it is a gap for subtler subtype work.
  • Per-sample missingness up to 23% is tolerated (threshold 25%). High-missingness samples are retained and imputed downstream (see §5).

3 Differential methylation

Per probe and per contrast, the pipeline computes group mean β, the difference Δβ = βtumour − βnormal, a two-group test, and Benjamini–Hochberg FDR. Output schema (differential_methylation.tsv):

Strengths
  • Effect-size gating (|Δβ| ≥ 0.20) on top of FDR — essential here, because 321,823 probes clear FDR<0.05 and the p-value alone is uninformative at this sample size.
  • Direction (hyper/hypo) is retained throughout, enabling direction-aware interpretation.
  • Group n per probe is reported, exposing where a contrast rests on few samples.
Caveats
  • 91:1 class imbalance (791 tumour vs 97 normal). Means are well estimated, but any per-probe test should be read with the imbalance in mind.
  • The exact two-group test statistic is not surfaced in the summary tables (only p_value/fdr). Confirm in run_brca_methylation_pipeline.py whether it is a t-test / Mann–Whitney / limma-style model before quoting it in a methods section.
  • β-value variance instability (see §1) is not addressed by a transform.

4 Biomarker panel construction

A 20-CpG panel is assembled from the differential results: 12 general tumour markers (tumour-vs-normal) + 8 Basal-skewed markers (Basal-vs-non-Basal), prioritised by abs_delta_beta and FDR, with gene-level de-duplication. Schema in phase3_panel/refined_biomarker_panel.tsv carries panel_rank, panel_role, source_run, probe_id, gene, delta_beta, fdr, direction.

Strengths
  • Compact and interpretable (per-gene, not a black box); mixes general + subtype-specific roles.
  • Gene-level de-duplication avoids stacking multiple probes of one locus.
Caveats — read before quoting the panel
  • Selection on the full cohort. The 20 probes were chosen using all samples, so the exact panel composition carries optimistic selection bias. This is the single most important caveat for the panel and is handled head-on in §5.
  • Treat the 20 CpGs as an exploratory candidate signature, not a locked, externally re-derived panel.

5 Validation & the leakage audit

This is the methodological core. Two evaluations were run, and a leakage audit was performed because near-perfect AUCs demand it.

5.1 The leakage found

The original Phase-4 internal CV pre-selected the 20-CpG panel on the full cohort, then ran 5-fold CV that re-used those fixed probes and only re-fit the classifier per fold. That is textbook selection leakage: feature choice saw the test folds.

5.2 The correction — nested CV

run_phase4_validation_nested.py re-ranks probes by train-only |Δβ| inside each fold, drawing candidates from the retained probe universe, then fits and scores. Feature selection never sees the held-out fold.

Why the near-perfect AUC is believable
  • ΔAUC ≈ 0.0004 between leaky and nested evaluation — if the score were a selection artifact, removing the leak would collapse it. It didn't.
  • External generalisation to an independently generated cohort (GSE66695) with no refitting.
  • Stage-stable: Stage I–IV AUCs span only 0.9948–0.9991 — not driven by late-stage outliers.
  • Consistent with the known biology: tumour vs normal methylation is genuinely, strongly separable.
Technical caveats found in the validation code
  • Nested folds ≠ the published 20-panel. The nested script uses a simpler pure-Δβ rule, so its fold panels have zero overlap with the original 20 CpGs (15 probes common across all 5 folds, 29 in the union). So the nested CV validates that an honest pipeline reaches ~0.996 — it does not re-validate the specific 20-CpG composition.
  • Imputation bleed: in load_tcga_matrix, missing β are filled with full-matrix column means (train+test together). A minor optimistic bias; negligible at this effect size, but a purist would impute within the training fold.
  • Class imbalance in folds: stratified 5-fold on 97 normals ≈ 19 normals/fold — small denominators make per-fold AUC noisier than the tight SD suggests.
  • External AUC of 1.000-ish should be read as “saturated/easy contrast,” not as evidence of clinical-grade discrimination.

6 Pathway enrichment

Pure-Python over-representation analysis (ORA) via scipy.stats.hypergeom. The test is correctly specified: query and term gene sets are both intersected with the background universe before testing.

# per term, per library
p = hypergeom.sf(overlap_n - 1, universe_size, len(term_genes ∩ background), query_size)
# query  = significant genes ∩ background
# universe = 33,010 genes from 382,924 retained probes
# BH-FDR applied per library

6.1 Three deliberate bias controls

  • Sharp query — canonical run = top 2,000 probes by |Δβ| (after FDR<0.05) → tumour 1,474 genes (1,045 hyper / 463 hypo); Basal 1,187. Tuned so the query sits in the 500–3,000-gene window where ORA discriminates.
  • Analyzable-gene background — the 33,010 genes covered by retained probes, not the whole genome. This is the key control against array-coverage bias.
  • Gene-level collapse — each gene counted once regardless of probe count, neutralising most 450K probe-number bias.

Strengths
  • Correct hypergeometric specification with the right background — the most common ORA error (whole-genome background) is avoided.
  • Hyper/hypo tested separately and combined; full ranked tables retained (16,221 GO-BP terms, etc.) — no cherry-picking.
  • Threshold sensitivity was explored (0.30, 0.40, top-1000, top-2000) before fixing the canonical run.
Caveats — the weakest layer of the project
  • Residual 450K neuronal/developmental artifact persists even at top-2,000. Gene-level collapse mitigates but does not eliminate probe-number bias; a probe-aware model (missMethyl::gometh, R) would be the rigorous fix and is intentionally not used.
  • No promoter vs gene-body resolution. The probe→gene map does not localise the CpG, so “hyper = silencing” is interpretive, not mechanistic.
  • DNA repair did not reach significance and is explicitly not claimed — a deliberate negative result worth stating.
  • Enrichr gene-set symbol matching means non-coding / clone IDs (e.g. AL009179.2) won’t map to gene sets and silently drop out of ORA.

7 Data-integrity notes (surfaced during review)

These are subtle items a careful reviewer should know. None are fatal; all are disclosed for transparency.

Probe-count reconciliationThe differential table holds 486,427 probes, but QC reports only 473,884 post-annotation and 382,924 retained. So differential testing ran on a broader probe set than the QC-defined analyzable universe. This is internally safe — enrichment uses only the 382,924-probe background, and significant probes outside it simply don’t map into the ORA universe — but the three numbers should be reconciled in any formal methods write-up.
“Top markers” files contain tiny-n rowsSome rows in top_hypermethylated_markers.tsv have normal_n = 1 (e.g. a probe with 395 tumour vs 1 normal). These per-subgroup edge rows should not be read as robust markers; the validated panel and CV do not depend on them, but don’t quote them in isolation.
DeterminismCV uses a fixed seed (random_state=0), so the nested results are reproducible. The 2.8 GB matrix is streamed twice in the nested script (two full passes) — correct but slow; a single-pass refactor is a pure-performance opportunity.

  --config project_b/brca_local_inputs.json --validate-paths-only

python3 project_b/scripts/run_phase4_validation_nested.py

# 3 — pathway enrichment (canonical tuned run)
python3 project_b/scripts/run_pathway_enrichment.py \
  --config project_b/brca_local_inputs.json --top-n-probes 2000
Strengths
  • Self-contained, project-relative paths; large matrix referenced in place (symlinked) to avoid 2.8 GB duplication.
  • Version-pinned gene-set GMTs cached locally; fixed CV seed; a fast path-validation mode.
Caveats
  • The β-matrix symlink means full reproduction on another machine requires re-supplying that 2.8 GB file.
  • No requirements.txt / lockfile or container is described — pin pandas/numpy/scikit-learn/scipy versions for exact reproduction.

Bottom line for a bioinformaticianThe classification claim is methodologically sound and defensible — the leakage audit + nested CV + external validation is exactly the right chain, and the numbers were recomputed from on-disk artifacts. Present the validated tumour-vs-normal signal as the result, the differential analysis as the engine, and the pathway enrichment as supporting, association-level evidence with its artifact disclosed. Every caveat above is a bound on interpretation, not a flaw in execution.
